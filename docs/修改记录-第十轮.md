## 这轮修了什么

### 1. 默认视角：角色不再站在画面中央
- 角色模型默认隐藏（`player.visible = false`），只有点「🧍 走进世界」才出现。
- 退出操控（`exitPlay`）后角色隐藏，镜头回到进入前的视角。
- 从小屋出来时先隐藏角色，如果原本在操控中再由 `enterPlay` 显示。

### 2. 菜单从 30 项收成「常用 6 项 + 3 个折叠分组」
- 顶部常用区：🗺 心情地图 / ❐ 心情日记 / 🫂 陪我待一会儿 / 🌠 一起看星星 / 🏡 去看看树屋 / ⓘ 关于与隐私。
- 其余收进「陪一陪·玩一玩」「记录与回看」「世界与设置」三组，默认折叠，点标题展开（支持键盘 Enter/空格）。
- 菜单宽度微调，常用按钮文字不换行。

### 3. 新手引导不再挡底部控件
- 引导出现时给 `body` 加 `onboarding`，临时隐藏心情胶囊、状态角标、「今天不想写」和右下引导字。
- 跳过/完成后移除，底部恢复。

### 4. 「回到最初的世界」重置更彻底
- 重置会先退出操控、小屋、看星星、新手引导，隐藏角色，移除 `playing/in-room/onboarding` 状态类。
- 镜头直接回到默认俯瞰（`phi 1.08 / dist 20 / target (0,1.7,6)`），天色立即到位。
- 顺带修正了冒烟测试里「重置」用例（现在会先弹确认）。
