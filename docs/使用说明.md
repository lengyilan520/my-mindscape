# 精神世界 · 使用说明

> 单文件离线版，双击 `index.html` 即可打开。推荐 Chrome / Edge。

---

## 一、第一次打开

1. 会有一个 3 步新手引导（写心情 / 走进世界 / 还有更多），可跳过。
2. 底部输入框写下今天的心情，回车或点「告诉森林 ↗」。
3. 世界会换天气与光，对应动物会走过来陪你。
4. 右上角「⋯」里是全部功能，已整理为**常用 6 项 + 3 个折叠分组**。

底部快捷胶囊：
- 今天有点累 / 一件开心的事 / 想安静待一会儿 / 我坚持下来了
- 今天不想写 · 陪我发会儿呆

---

## 二、情绪与陪伴

- 能认出：难过、焦虑、生气、疲惫、开心、骄傲、感恩，以及「想独处」「说不清」「危机」
- 否定句（「我不难过」）、强度（「特别难过」）、混合情绪（「又累又焦虑」）都会被照顾
- 会引用你说过的话：当天「刚才你说…」，隔天「上次你说…，我记着呢」
- 心情卡片里：
  - 💬 想多说说：继续聊 2–3 轮
  - 🫂 陪我待一会儿：安静陪伴模式
  - 其他小练习：深呼吸 / 专注一会儿 / 把情绪放出去
- 写下很重的念头时：会先接住你，给出热线 **12356**，并明确「我是程序，不是专业人士」

## 三、记忆与回顾

| 功能 | 位置 | 说明 |
|------|------|------|
| 心情日记 | ⋯ 常用区 | 最近记录、连续天数，可给过去的自己回一句 |
| 心情地图 | ⋯ 常用区 | 最近 30 天色块（深浅=当天次数），点某天看原话，可导出图片 |
| 情绪的起落 | ⋯ → 记录与回看 | 情绪曲线 |
| 我的天气相册 | ⋯ → 记录与回看 | 心情对应天气的回顾 |
| 我这一年 | ⋯ → 记录与回看 | 一年总结信，可朗读、存图片 |
| 那年的今天 | ⋯ → 记录与回看 | 翻看往年同一天 |
| 时间胶囊 | ⋯ → 记录与回看 | 写给未来/过去的自己 |
| 生灵图鉴 | ⋯ → 记录与回看 | 每只动物的亲密度与召唤 |
| 存一张明信片 | ⋯ → 记录与回看 | 导出图片 |

- 数据只存本机浏览器，不上传
- 自动备份：每天一份，保留 7 天
- 「ⓘ 关于与隐私」可查看记忆大小、帧率，并导出 / 导入 / 恢复备份 / 清空

## 四、走进世界（第一人称）

点右上「🧍 走进世界」：

- 桌面：WASD / 方向键走动，Shift 跑，空格跳，E 进屋/上树屋，Esc 退出
- 手机：左下摇杆，右侧「跑 / 跳」
- 靠近小屋或树屋会出现交互提示
- 退出后角色收起，镜头回到之前的视角

### 小屋
- 进小屋可以亲手布置：床位、家具、墙纸、风格
- 清空/重置/出门在面板底部

## 五、森林与生灵

- 天气：情绪会改变天色、雨雪、彩虹、烟花等
- 时间：⋯ → 时间，五个时段（跟随现实/夜/黄昏/清晨/白天），会自动渐变
- 环境音：风 / 水 / 鸟 / 虫，随时间段变化；可整体静音
- 看星星：把镜头抬向星空，可以许愿（愿望进日记，3 天后回访）
- 树屋：心情卡片里「一起搭树屋」→ 三次选择 → 竣工后可扩建（秋千/二层/灯串）
  - 「🏡 去看看树屋」可随时把镜头转过去
- 动物：点一下会跑过来；卡片里「🍎 喂它」增加亲密度；图鉴可召唤
- 篝火：点一下点燃/熄灭，同时开始/停止篝火音乐会

---

## 六、画面与无障碍

- ⋯ → 画质：低 / 中 / 高；手机默认低，帧率过低会自动降档
- ⋯ → 大字护眼：放大界面文字
- 键盘：Esc 关闭弹窗，菜单支持 Tab 与 Enter
- 减少动效：遵循系统 `prefers-reduced-motion`

---

## 七、隐私与备份

- **不联网、不上传**；页面不发起网络请求
- 日记、亲密度、世界布置都在 `localStorage`
- 清除浏览器站点数据会丢失，建议定期「导出记忆」
- 「导入记忆」可恢复；「恢复最近备份」可回到自动备份

---

## 八、常见问题

**Q：刷新后世界会重置吗？**
A：不会。心情、树屋、造物、时间、画质、开关都会被记住。

**Q：换电脑会丢吗？**
A：会。先「导出记忆」得到 JSON，到新电脑「导入记忆」。

**Q：手机上卡？**
A：⋯ → 画质调到「低」；关闭其他后台应用。

**Q：为什么没有联网 AI？**
A：当前版本刻意保持完全离线与隐私；情绪理解是本地词库 + 打分，不请求网络。
